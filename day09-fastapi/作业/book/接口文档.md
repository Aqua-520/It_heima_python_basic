## 1. 访问首页

**接口地址**: `/`

**请求方式**: `GET`

**接口描述**: 返回书籍管理的前端页面

**请求参数**: 无

**请求示例**: `/`

**响应参数**: 返回 `index.html` 静态页面 (Content-Type: text/html)

---

## 2. 查询书籍列表

**接口地址**: `/api/books`

**请求方式**: `GET`

**接口描述**: 查询所有书籍列表，按编号升序返回

**请求参数**: 无

**请求示例**: `/api/books`

**响应参数**:

| 参数名称       | 类型     | 备注                       |
| -------------- | -------- | -------------------------- |
| code           | integer  | 状态码, 200: 成功          |
| message        | string   | 提示信息                   |
| data           | object[] | 书籍列表数据               |
| \|- id         | string   | 书籍编号                   |
| \|- title      | string   | 书名                       |
| \|- author     | string   | 作者                       |
| \|- publisher  | string   | 出版社                     |
| \|- total_pages| integer  | 总页数                     |
| \|- price      | float    | 价格                       |

**响应示例**:

```json
{
    "code": 200,
    "message": "查询成功",
    "data": [
        {
            "id": "BK001",
            "title": "三体",
            "author": "刘慈欣",
            "publisher": "重庆出版社",
            "total_pages": 302,
            "price": 23.00
        },
        {
            "id": "BK002",
            "title": "活着",
            "author": "余华",
            "publisher": "作家出版社",
            "total_pages": 191,
            "price": 28.00
        }
    ]
}
```

## 3. 新增书籍

**接口地址**: `/api/books`

**请求方式**: `POST`

**接口描述**: 新增一本图书信息，编号由用户录入

**请求参数**:

| 参数名称    | 参数说明 | 是否必须 | 数据类型 |
| ----------- | -------- | -------- | -------- |
| id          | 编号     | 是       | string   |
| title       | 书名     | 是       | string   |
| author      | 作者     | 是       | string   |
| publisher   | 出版社   | 是       | string   |
| total_pages | 总页数   | 是       | integer  |
| price       | 价格     | 是       | float    |

**请求示例**:

```json
{
    "id": "BK003",
    "title": "百年孤独",
    "author": "加西亚·马尔克斯",
    "publisher": "南海出版公司",
    "total_pages": 360,
    "price": 39.50
}
```

**响应参数**:

| 参数名称       | 类型    | 备注                      |
| -------------- | ------- | ------------------------- |
| code           | integer | 状态码, 200: 成功         |
| message        | string  | 提示信息                  |
| data           | object  | 新增的书籍数据            |
| \|- id         | string  | 书籍编号（用户录入）      |
| \|- title      | string  | 书名                      |
| \|- author     | string  | 作者                      |
| \|- publisher  | string  | 出版社                    |
| \|- total_pages| integer | 总页数                    |
| \|- price      | float   | 价格                      |

**响应示例**:

```json
{
    "code": 200,
    "message": "新增成功",
    "data": null
}
```

## 4. 删除书籍

**接口地址**: `/api/books/{book_id}`

**请求方式**: `DELETE`

**接口描述**: 根据编号删除指定的书籍

**请求参数**:

| 参数名称 | 参数说明 | 是否必须 | 数据类型 |
| -------- | -------- | -------- | -------- |
| book_id  | 书籍编号 | 是       | string   |

**请求示例**: `DELETE /api/books/BK001`

**响应参数**:

| 参数名称 | 类型    | 备注                    |
| -------- | ------- | ----------------------- |
| code     | integer | 状态码, 200: 成功       |
| message  | string  | 提示信息                |
| data     | null    | 无返回数据              |

**响应示例**:

```json
{
    "code": 200,
    "message": "删除成功",
    "data": null
}
```

## 附录: 通用说明

### 状态码说明

| 状态码 | 说明                     |
| ------ | ------------------------ |
| 200    | 请求成功                 |
| 400    | 编号已存在               |
| 404    | 书籍不存在               |
| 500    | 服务器内部错误           |

### 统一响应格式

所有API接口均返回以下统一格式:

```json
{
    "code": 200,
    "message": "提示信息",
    "data": null
}
```

- `code`: 状态码 (integer)，200 表示成功
- `message`: 提示信息 (string)
- `data`: 响应数据 (any)，具体结构见各接口定义

### 数据存储说明

- 书籍数据以 JSON 格式存储在 `data/books.json` 文件中
- 书籍编号（id）由用户录入，新增时若编号已存在则返回 400 错误
- 每次新增书籍后，数据将自动持久化到文件中
